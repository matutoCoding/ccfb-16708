# 激光秀编排与安全预演系统

浏览器端的激光秀编排、三维预演与照射安全评估系统。TypeScript + 自写 WebGL2 着色器,工程数据持久化在 IndexedDB,无需后端。

## 功能页面

| 页面 | 能力 |
| --- | --- |
| 工程列表 | 新建 / 复制 / 删除 / 自动保存 / `.lspkg` 打包导出与导入 |
| 场地与设备 | 舞台、观众区三维 AABB;烟雾浓度分区(散射系数);激光器位置、朝向、扫描角、功率/发散角/波长/PPS 等规格 |
| 素材库 | 导入 ILDA(格式 0/1/2/3/4/5,含调色板段)、坏文件中文报错、WebGL2 二维预览、音频波形 |
| 时间线编排 | 每轨对应一台激光器;片段拖动、切开、拼接、变速、灭光,与音频波形对齐 |
| 三维预演 | 烟雾中体积光束(浓处亮)、振镜跟速失真与饱和闪烁、轨道相机、安全热力图叠加 |
| 安全检查 | 全节目逐时间步全网格评估、越界清单、一键生成限区遮罩、导出带遮罩 ILDA 与评估报告 |
| 设置 | 网格间距、MPE 告警比例、遮罩余量/分辨率、时间步长、皮肤限值开关 |

## 物理与安全模型

### 光束(基模高斯 TEM00,1/e² 口径)

```
w(z) = w0 · sqrt(1 + (z/zR)²)          束半径
zR   = π · w0² / λ                      瑞利长度
w0   = λ / (π · θ_半)                   由发散角规格反推束腰
E(0,z) = P·(1 − exp(−2a²/w²)) / (πa²)   7mm 人眼孔径平均轴上辐照度
E(r,z) = E(0,z) · exp(−2r²/w²)          离轴高斯包络
```

### IEC 60825-1:2014 眼 MPE(可见光 400–700nm,点光源)

| 曝光时间 t | 能量密度限值 H_MPE |
| --- | --- |
| t ≤ 0.25 s | `18 · t^0.75` J/m² |
| 0.25 < t ≤ 10 s | `10 · t^(1/3)` J/m² |
| t > 10 s | 恒 `2.154` W/m² |

重复脉冲:单脉冲限值乘 `n^(−1/4)`,n 为 0.25s 评定窗内离散驻留数。皮肤限值可选(2000·t^0.25 J/m²,长时 1000 W/m²)。

### 完备性(不漏检)设计

1. 观众区所有 AABB 合并为规则三维网格,**逐格**评估,不做射线投射;
2. 时间步长取最小 `1/PPS`,每个脉冲位置都是评估时刻;
3. 每步对每格做四类检查:单脉冲、0.25s 平均窗、10s 长窗、多脉冲修正;多机功率在同格同时刻直接叠加;
4. 扫描角锥剔除只是性能优化,条件本身保守,不改变任何被评估点结果;
5. 安全引擎始终按**指令角度**评估(不依赖振镜模拟失真),保证指令会到的地方都纳入。

## 验证

```bash
npm install
npm test          # 34 个单测,含手算对照(误差 <2%)与全网格穷举不漏检证明

npm run dev
npm run build
```

### 手算对照测试(硬要求)

- `test/physics.test.ts`:束腰、瑞利长度、10m/30m 轴上与离轴辐照度、各曝光时间 MPE、多脉冲因子,逐项与独立手算值对照,误差 <2%;
- `test/engine.test.ts`:8 组典型工况(静态直射、低功率合格、10s 长窗、离轴、双机叠加、灭光、扇面多脉冲、确定性 n=25 多脉冲)+ **75 格 × 全时间步的独立穷举实现逐格比对**,同时验证不漏检(穷举判超标的格引擎必有违规)与不误报。
